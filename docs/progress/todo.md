# 待办（阻断生产上线）

本轮 0.1.0 精简不改变以下上线门槛；主线合并与版本号不代表完成生产验收。

## 当前优先顺序

暂停功能扩充，先完成下面三项，再进行最终镜像及服务器部署验收。日常构建/镜像 CI 仍作为回归检查，不代表最终放行。

1. **资源边界**：统一入口正文、上传、出站响应和媒体下载的大小限制；限制生成与轮询并发，并落实超时、磁盘容量与超限错误。现有 `handler/storage.go` 上传仍整体读入内存，`service/video_task.go` 按任务启动 goroutine。具体数值及排队/拒绝策略先说明影响并确认，不静默套用经验值。
2. **会话凭据**：复核浏览器凭据持久化与文件访问方式；现有 token 在 JavaScript 可读的持久存储中。评估迁入 HttpOnly/Secure/SameSite Cookie，并一起验证 CSRF、代理、退出、改密、禁用、跨标签页与重启后的行为。已有服务端会话撤销不等于浏览器侧凭据保护已完成。
3. **更新恢复**：为数据库/配置建立显式版本与兼容性检查；提供停写一致性备份、密钥独立备份、恢复校验和回滚步骤。在备份副本上跨版本验证账号、媒体、API 配置、画布及任务；当前 `AutoMigrate` 和同版本重启测试不足以通过此项。

## 其余上线门槛

- 导演台：完成真实双账号跨设备保存/媒体恢复及旧导演台工程格式迁移评估；不恢复未审查的时间轴/视频导出二进制。

- 依用户要求建立保留既有数据的版本化数据库/配置迁移与回滚保护，替代仅依赖启动 AutoMigrate 的升级假设。在备份副本验证更换容器/应用版本后账号、个人 API、管理员中转渠道、画布、媒体及任务仍完整；当前仅完成同版本重启恢复。

- Docker 方案已确定；实际镜像与 Compose CI 40086299774 全通过，当前扫描 0 中高危及低危、1 UNKNOWN。候选基础镜像迁至 Wolfi 的公告覆盖、源码修复、CPU/locale 与真实服务器兼容性仍需验收。旧 Debian CVE 不因换发行版无扫描匹配自动关闭；Compose/Rootless/出站 ACL 与数据恢复需在目标环境验收。

- 最终镜像 CI、组件清单/SBOM、高危扫描和隔离运行已通过；继续复核保留的中低危匹配及静态捆绑 native 组件。完成实际宿主机出站 ACL、Nginx/TLS/日志配置审查，部署时固定待发布镜像摘要。
