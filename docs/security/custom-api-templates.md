# 自定义图片 API 模板

本轮沿用账号渠道和现有 JavaScript 参数转译，没有新增供应商注册系统，也没有预置渠道、模型、地址或密钥。普通 OpenAI/Gemini 调用保持原协议；特殊字段只由渠道明确保存的模板控制。

## 模板扩展

| 字段 | 用途 |
| --- | --- |
| `rawPrompt` | 用户原始提示词，不叠加系统提示或提示词保护前缀 |
| `rawSize` | 原始比例或尺寸；不采用通用像素换算 |
| `quality` | 面板选定或自定义的原始值；模板明确区分分辨率档位与供应商质量字段 |
| 模型内 `references` | 静态 `{format:"auto" / "url" / "dataUrl", max?:整数}`；声明编码及接口支持的数量，不静默丢参考 |
| 请求内 `parts` | `formData` 的有序字段数组；文本使用 `{name,value}`，图片使用 `{name,file,filename?}`，不能同时指定 `body` |
| 模型内 `content` | 显式 `{url:"/jobs/{taskId}/content"}`；成功查询没有结果时，带原查询鉴权下载同源图片 |

未声明的模板沿用原输入规则。`parts.file` 必须是真实图片 Data URL；服务端检查 MIME/内容，使用 Go 标准库生成 multipart 边界。普通表单 `body` 仍是文本字段，不把 URL 字符串伪装成文件。

`references.format=url` 复用服务器媒体和现有受控授权链接。本地 blob/Data URL 先通过已登录账号上传；站内私人媒体按归属签发链接；站外 HTTP(S) URL 保持原值。不把登录 Token 发给供应商。数量超过接口声明时在上传前明确报错。公开渠道只提供编码/数量元数据，不暴露模板全文和 Key。

`content` 只用于明确配置的异步图片，且必须存在 `poll`。同源 `/videos/{id}/content` 图片结果也能带鉴权下载。检查协议、主机、userinfo 和实际图片类型，拒绝下载重定向、HTML、错误 JSON、空文件。错误的字符串结果路径继续报错，不猜下载地址、不重新提交付费请求。原有视频的延迟内容下载规则保留。

图片设置新增 1K/2K/4K 选项及自定义质量、比例/尺寸输入。模板必须按供应商合同验证映射；不把通用 quality=high 自动解释为某个分辨率。不新增按模型保存参数的功能。

## 其他修复

后台曾把服务器本地存储 `local` 误转成 `s3`，保存渠道权限时触发混合存储报错。现在保留本地类型和稳定 ID，服务端拒绝把保留的本地存储 ID 改成其他类型。自定义渠道与普通用户云端渠道可同时开启，关闭后的后端权限仍生效。真实混合存储限制没有被跳过。

平台 UI 使用 ICAN，功能名称使用“画布”。登录页去掉标题和说明，仅保留标识及表单。上游署名、许可、已有存储键及用户数据未重命名。

## 验证与边界

- Go 合同测试：有序二进制表单、原始提示词/尺寸、编码与数量校验、异步创建/查询/内容下载、PNG/JPEG、HTML/JSON/空内容拒绝、跨域/userinfo/重定向及错误结果路径。
- 配置回归：同时启用两种渠道能力，保留存储、渠道 ID、模板和密钥；普通用户个人渠道可用；关闭后拒绝。
- Web 测试：静态元数据、旧模板、站内授权/站外链接、本地 blob/Data URL、上传失败、数量上限及会话变化。
- 实际构建、浏览器和镜像结果见 `evidence/custom-api-local.json` 及本版本 GHCR 发布记录。
- 供应商专用配置单独交付，不进入公开仓库。只运行无费用 fixture；真实供应商返回、收费、可达性和长任务需要授权后验收。未执行外部插件、自动更新器或图床凭据逻辑。

本轮没有新增数据库列或改变现有配置字段格式：可选声明保存在原模板字符串里。原模板、渠道稳定 ID、账号配置、数据库、媒体和加密密钥保留。使用新语法的模板需要本版运行时；回滚前恢复原模板或恢复更新前一致性备份，不能在旧镜像上继续使用新模板。既有跨版本恢复、资源边界和生产环境待办见 `../progress/todo.md`。


## v0.1.3 界面配置

个人设置的“新增自定义 API”可选择空白自定义、OpenAI 兼容或通用异步视频，也可导入 JSON。预设仅初始化新渠道，不修改已有渠道。输入真实基础地址、模型名称和个人 Key；在“接口配置 → 自定传参转译 → 表单配置”逐模型编辑。管理员渠道沿用同一转译编辑器；公共信息仅返回输入声明，不返回 Key 或完整请求规则。

表单覆盖 JSON、普通表单、URL 编码请求，Bearer、自定义请求头或明确无鉴权，嵌套字段映射、固定 JSON 值、字符串转换、可选字段、单图/多图/首尾帧条件，异步查询、状态/进度路径、结果路径和同源鉴权下载。预设路径均可改；相对路径追加到 Base URL，系统不补齐或去重 `/v1`。POST 查询、动态提取函数和二进制 multipart 等既有能力继续通过高级编辑器配置，不新增执行引擎。

每个模型分别声明时长、分辨率、比例和参考模式选项，选择是否允许自定义。声明不包含默认值，不根据名称猜模型能力；已有值超出声明时提示错误，服务端在创建请求前拒绝。视频精确映射使用 `rawPrompt`、`rawSize`、`rawSeconds`、`resolution`；旧模板的 `prompt`、数值 `seconds` 和归一化 `aspectRatio` 保留原语义。没有声明的普通协议沿用旧逻辑。

新表单规则收到未声明的参考类型会在提交前报错，避免静默丢弃素材；按模型合同先配置映射与编码。对明确要求 URL 的图片、首尾帧、视频和音频，复用登录上传与单文件限时授权。上传失败、账号切换、他人文件、站内登录路径、blob/Data URL 直传均有拒绝用例。没有公开目录；链接有效期仍由管理员原配置决定。素材变量在服务器再次按归属授权。视频/音频此次只新增 URL 准备，不新增二进制转码能力。

未知轮询状态继续等待，不创建新付费任务。显式内容下载沿用查询鉴权，只允许同源，拒绝所有重定向；视频下载按实际媒体字节确定类型，拒绝伪装成视频的 HTML/JSON/空内容。其他自定义提交和轮询拒绝跨来源重定向，保留原有 DNS/IP、管理员私网例外和请求限制。未新增大小、并发或超时默认值；现有工作台上传边界保留。自定义工作台与画布不再套用旧的模型名称参数转换，原始请求值和首尾帧分别传递。

### 导入、导出与兼容

JSON 文件使用 `format: "ican-channel"`、`version: 1`，包含名称、地址、协议、模型列表、能力和表单配置。无 API Key、会话凭据或存储密钥；拒绝凭据字段、未知版本/字段、缺失必要路径和状态。导入创建新 ID。现有编辑器内导入只允许相同渠道地址/协议且不覆盖已配置模型。

表单编译为现有 `parameterTranslation` 字符串。`ICAN_FORM_V1` 注释仅保存可视化编辑信息；编辑器验证其与编译结果完全一致，不能用过时表单覆盖已手改的代码。执行时服务端仍使用原有 Goja 沙箱，不读取注释、不增加网络/文件/进程绑定。已有高级规则原样保留；无法证明无凭据的任意高级代码不自动导出，仍可在高级编辑器审查、复制和编辑。

这是追加式配置版本：原数据库表、账号、渠道 ID、Key、素材、画布和任务结构不变，不批量改写旧配置。新增 `inputs.version: 1` 静态声明，未声明时保持旧行为。公共模板与个人凭据继续使用现有权限和账号持久化路径。

更新前停机备份完整数据目录及原加密/会话密钥；使用新镜像 digest 启动，完成配置跨设备恢复检查。若回滚到 v0.1.2，必须同时恢复更新前的配置备份：旧客户端不认识新的原始时长变量，不能直接保留新规则并降级。恢复备份前保留升级后数据副本，不能覆盖期间的新素材或任务。服务器只拉取 CI 镜像，不编译。

### 验证范围

共享 JSON/JS fixture 同时用于前端导入导出和后端真实转译请求验证；包括单图/多图/首尾帧映射、字符串参数、声明拒绝、四阶段异步状态、快照恢复、鉴权下载及重定向拒绝。所有供应商请求为本地替身，没有调用付费生成。公开 fixture 使用虚构模型和保留域名；真实供应商实例单独交付，不进入预设或公共仓库。
