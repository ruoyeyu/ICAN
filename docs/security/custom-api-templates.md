# 自定义图片 API 模板

本轮沿用账号渠道和现有 JavaScript 参数转译，没有新增供应商注册系统，也没有预置渠道、模型、地址或密钥。普通 OpenAI/Gemini 调用保持原协议；特殊字段只由渠道明确保存的模板控制。

## 模板扩展

| 字段 | 用途 |
| --- | --- |
| `rawPrompt` | 用户原始提示词，不叠加系统提示或提示词保护前缀 |
| `rawSize` | 原始比例或尺寸；不采用通用像素换算 |
| `quality` | 面板选定或自定义的原始值；模板明确区分分辨率档位与供应商质量字段 |
| 模型内 `references` | 静态 `{format:"auto" / "url" / "dataUrl", max?:整数}`；声明编码及接口支持的数量，不静默丢参考 |
| 请求内 `parts` | `formData` 的有序字段数组；文本使用 `{name,value}`，图片使用 `{name,file,filename?}`，不能同时指定 `body` |
| 模型内 `content` | 显式 `{url:"/jobs/{taskId}/content"}`；成功查询没有结果时，带原查询鉴权下载同源图片 |

未声明的模板沿用原输入规则。`parts.file` 必须是真实图片 Data URL；服务端检查 MIME/内容，使用 Go 标准库生成 multipart 边界。普通表单 `body` 仍是文本字段，不把 URL 字符串伪装成文件。

`references.format=url` 复用服务器媒体和现有受控授权链接。本地 blob/Data URL 先通过已登录账号上传；站内私人媒体按归属签发链接；站外 HTTP(S) URL 保持原值。不把登录 Token 发给供应商。数量超过接口声明时在上传前明确报错。公开渠道只提供编码/数量元数据，不暴露模板全文和 Key。

`content` 只用于明确配置的异步图片，且必须存在 `poll`。同源 `/videos/{id}/content` 图片结果也能带鉴权下载。检查协议、主机、userinfo 和实际图片类型，拒绝下载重定向、HTML、错误 JSON、空文件。错误的字符串结果路径继续报错，不猜下载地址、不重新提交付费请求。原有视频的延迟内容下载规则保留。

图片设置新增 1K/2K/4K 选项及自定义质量、比例/尺寸输入。模板必须按供应商合同验证映射；不把通用 quality=high 自动解释为某个分辨率。不新增按模型保存参数的功能。

## 其他修复

后台曾把服务器本地存储 `local` 误转成 `s3`，保存渠道权限时触发混合存储报错。现在保留本地类型和稳定 ID，服务端拒绝把保留的本地存储 ID 改成其他类型。自定义渠道与普通用户云端渠道可同时开启，关闭后的后端权限仍生效。真实混合存储限制没有被跳过。

平台 UI 使用 ICAN，功能名称使用“画布”。登录页去掉标题和说明，仅保留标识及表单。上游署名、许可、已有存储键及用户数据未重命名。

## 验证与边界

- Go 合同测试：有序二进制表单、原始提示词/尺寸、编码与数量校验、异步创建/查询/内容下载、PNG/JPEG、HTML/JSON/空内容拒绝、跨域/userinfo/重定向及错误结果路径。
- 配置回归：同时启用两种渠道能力，保留存储、渠道 ID、模板和密钥；普通用户个人渠道可用；关闭后拒绝。
- Web 测试：静态元数据、旧模板、站内授权/站外链接、本地 blob/Data URL、上传失败、数量上限及会话变化。
- 实际构建、浏览器和镜像结果见 `evidence/custom-api-local.json` 及本版本 GHCR 发布记录。
- 供应商专用配置单独交付，不进入公开仓库。只运行无费用 fixture；真实供应商返回、收费、可达性和长任务需要授权后验收。未执行外部插件、自动更新器或图床凭据逻辑。

本轮没有新增数据库列或改变现有配置字段格式：可选声明保存在原模板字符串里。原模板、渠道稳定 ID、账号配置、数据库、媒体和加密密钥保留。使用新语法的模板需要本版运行时；回滚前恢复原模板或恢复更新前一致性备份，不能在旧镜像上继续使用新模板。既有跨版本恢复、资源边界和生产环境待办见 `../progress/todo.md`。
