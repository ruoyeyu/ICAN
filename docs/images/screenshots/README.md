# Screenshot scope / 截图范围

Chinese images are browser screenshots of the existing ICAN production frontend. English images translate the rendered text and example content for documentation only; they do not represent an implemented English application locale. Layout, colors and application source are unchanged.

- Canvas: a local project with text, image and video nodes and connections. The LLM text is a hand-written fixture, not an inference result.
- Image/video workspaces: history records are seeded in the browser database. The landscape is an original geometric SVG fixture; the four-second video repeats that image. Success labels belong to the simulated records, not verified provider requests.
- API settings: `api.example.com`, demo model IDs and a nonfunctional placeholder key; no private endpoint or account is used.
- Browser: Chromium 153, 1600 × 1000 viewport, local CJK fallback font. Existing Next.js standalone build, without application source or stylesheet changes. UI implementation matches the previously built candidate; subsequent edits concern documentation only.
- Requests: local frontend assets are allowed; API responses are fixtures and external browser requests are aborted. No generation button is submitted and no paid inference is performed.
- Director mode remains disabled. These screenshots do not constitute server security, live provider, cross-device sync or production deployment acceptance.

中文截图为实际前端界面，英文图在截图时翻译显示文字，不代表应用已实现英文语言包；文案、媒体和历史记录全部使用本地模拟数据。模拟视频是静态插画组成的四秒片段，不展示真实模型质量或运动效果。截图未修改应用 UI、未使用私人接口、未付费调用，不能替代功能与安全验收。
