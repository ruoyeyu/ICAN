# 供应商模板

[English](supplier-templates.md)

公共项目只提供通用预设。每个站点自行添加供应商，不内置私有供应商的方法、地址、模型、密钥或远程模板订阅。

## 管理员怎么添加

1. 打开 **后台 → 设置 → 供应商模板**。
2. 点击 **新增模板**，填写名称、基础地址、模型和使用说明，沿用现有表单设置各模型接口。也可以 **导入模板**，使用个人渠道导出的无凭据 `ican-channel` v1 JSON。
3. 检查后点击 **保存模板**。用户重新打开“新增自定义 API”的模板选择器，就能看到它。

每个供应商可单独编辑、导出和删除。使用说明仅显示纯文本，不执行 HTML、脚本或加载外部图片。

编辑窗口可填写 **临时 API Key**，点击 **拉取模型**，复用管理员模型列表接口和现有选择器。支持搜索、复选框多选、全选/取消当前列表；已有模型保持勾选，新候选默认不勾选。点击 **确定** 才写入当前草稿，再点 **保存模板** 持久保存。取消或拉取失败保留原配置。临时 Key 不进入模板、导出文件或账号配置；关闭窗口、确认或取消选择后清除。获取列表不代表模型已验证可生成，也不会自动发起生成测试。未提供兼容模型列表接口的供应商仍可手动填写模型。

## 用户怎么使用

打开 **配置 → 本地直连 → 新增自定义 API**，选择站点模板，填写自己的 Key，添加渠道，最后点击配置页 **完成**。地址、模型、方法和参数已由模板带入；换设备登录后，通过现有账号同步恢复自己的渠道和 Key。切换供应商模板会清空草稿 Key，避免误带给另一供应商。

共享的是接口配置，不是管理员 Key。原有云端渠道独立保留；自定义渠道权限、请求发送方式及服务端校验沿用原逻辑。“本地直连”不表示所有特殊接口都在浏览器执行。

用户也可在同一入口导入自己的 JSON。添加渠道后保留为 **个人模板**，点击 **完成** 后随账号同步，其他用户不可见。选中后可点 **删除个人模板**，再点 **完成** 同步删除。

## 给本地 Agent / 运维

Compose 模板目录为 `/app/data/api-templates`，对应宿主机 `$ICAN_DATA_DIR/api-templates`。原生运行默认 `data/api-templates`，可通过 `API_TEMPLATE_DIR` 指定。目录属于原持久化数据卷，更新镜像不丢失，不增加数据库表或服务。

每家供应商一个 `<id>.json`。ID 以字母或数字开头，其余仅用字母、数字、下划线和连字符；后台自动生成 UUID。将导出模板放入目录即可：先写临时文件，写完后重命名为 `.json`，避免半成品。目录仅供服务账号和运维写入；容器 UID/GID 为 10001，后台创建文件权限为 0600。方法、说明和固定值中都不要写密钥。

重新打开选择器即可发现增删改，无需重启或编译。不联网订阅、不运行插件、不安装额外依赖。无效文件被排除并在后台提示；拒绝符号链接、特殊文件和目录越界。沿用现有 129 MiB 配置大小边界，没有新增硬盘配额或全局并发上限。

## 修改、删除和回滚

用户添加渠道时保留独立配置。模板更新或删除只影响后续选择，不覆盖已保存渠道、Key、素材或任务。采用新方法需主动重新配置，不会自动替换模型、参数或重复创建收费任务。删除站点模板会实际删除文件，没有第二份目录数据库或后台更新缓存需要清理。

更新前备份完整数据目录（含 `api-templates`）、部署配置和原加密密钥，继续使用原绑定目录和密钥。账号配置仅新增可选 `channelTemplates` 字段；旧客户端不提交此字段时，本版服务器保留原值，明确提交 `[]` 才删除。旧模板不带 `instructions` 也能导入。

回退旧镜像前保留当前数据库和目录备份：旧版本不显示新模板目录，保存配置时可能无法保留新增字段。需要时恢复匹配备份，不重新生成密钥或初始化数据库。参见 [更新与回滚](ghcr-deployment.zh-CN.md)。
