# ICAN 安全加固复核

状态：可复核候选版本，**不满足替换现站的全部条件**。未声称“绝对安全”，也未声称完成整站渗透、零日发现或生产验收。

## 基线与授权

采用 `tigerowo/infinite-canvas@e13006fbaeabe14e4a6d27cba667ff1473009ebc`；复核时上游 main 和用户参考 fork 均指向该提交。工作分支 `security/ican-hardening`，独立目录 `ICAN`，原审查副本未改动。

用户指定私有 `ruoyeyu/ICAN` 为项目仓库，并明确授权上传改动；公开 fork 仅供参考，未写入。用户随后说明 `/root/hb` 等路径来自另一台服务器，可以忽略路径文件。本环境没有其原始未提交补丁、api.txt、旧素材或服务器访问，因此本次不声称迁入那些文件。

## 模块边界

保留无限画布，图片、视频、音频流程，管理员用户管理，个人 API URL/Key/模型配置及账号同步，画布、素材和生成记录同步，已有任务查询/恢复结构。新增服务器本地私有媒体后端，管理员 S3/WebDAV 后端保留；普通用户个人存储和匿名上传关闭。

注册仅接受一次性邀请码。可配置渠道界面只提供自定义 API、OpenAI 兼容和 Gemini 协议，URL、Key、模型初始为空。未预置可调用的付费供应商。原协议适配代码部分保留用于维护，但不提供推广入口。

禁用 OAuth、Agent/Bridge/工作流/RunningHub/AutoDL、积分计费及远程提示词同步。后端中间件拒绝对应路由，自定义渠道也拒绝这些额外协议，相关后台 worker 不再启动/轮询。导演台入口和预编译资源、主机 Bridge 分发组件、自动 npm/镜像发布工作流、赞助图片和推广链接已移除。保留许可证及来源说明。

## 发现、修复和证据

| 边界 | 复核与改动 | 本次验证 |
|---|---|---|
| SSRF | 自定义渠道、转译、任务轮询、结果下载、素材抓取采用同一安全客户端；禁用环境代理；连接时检查全部解析 IP 并直接连接校验后的地址；拒绝回环、私网、链路本地、元数据/保留/地址转换段 | 地址矩阵、localhost、混合公网/私网 DNS 答案、元数据重定向、跨来源请求体/凭据转发测试 |
| 管理员私网例外 | WebDAV 仅允许管理员配置的精确来源；允许 RFC1918/ULA，仍拒绝回环与元数据；重定向不能逃出配置来源 | 源码复核；真实私网存储服务尚未验收 |
| 主动内容 | 图片代理必须登录；按实际内容嗅探被动媒体类型；HTML/SVG/未知格式拒绝；nosniff、sandbox CSP、私有缓存策略；Next 图片优化关闭 | 伪造 image/png 的 HTML、SVG、正常 PNG；生产 Next 图片优化端点拒绝 |
| 素材鉴权 | 元数据、内容、删除按所有者校验；相同来源文件不再公开；外部供应商使用独立 issuer/audience、限定对象和有效期的签名链接；可撤销并检查所有者禁用状态 | 两个账号及匿名读取，cookie 读取与 Range，授权链接、对象替换、撤销、跨账号签发/删除；生产联通上传和读取 |
| 用户/任务隔离 | 配置、画布及素材按账号；新发现图片/音频任务 `Save` 可按客户端 ID 覆盖其他用户记录，改为仅新增；视频更新条件补齐 user_id | 相同客户端任务 ID 的跨账号覆盖拒绝，原用户内容保留；画布读取/删除、素材记录、任务读取测试 |
| 自定义渠道开关 | 关闭后拒绝保存/选取个人渠道；后台仍独立检查权限和协议 | 直接服务调用绕过前端的负向测试 |
| 登录与会话 | 无默认管理员密码；邀请码哈希保存、原子消费、撤销/过期；JWT 固定算法/issuer/expiry/JTI，持久会话表；退出删会话，改密/禁用/角色变更撤销；敏感用户更新使用版本条件；cookie HttpOnly/SameSite；跨来源写请求拒绝 | 管理员/普通用户/匿名、邀请码重用和过期、退出、改密、禁用及重新启用旧令牌、CSRF、登录限流；生产 cookie 联通 |
| 密钥与日志 | 个人模型/存储配置和管理员私有配置以 AES-256-GCM 加密，关联数据绑定账号/字段；拒绝静默读取旧明文；应用日志只记固定事件和错误类型，AI 日志不存请求/响应正文；Gin panic 和 Next 代理不输出敏感 URL/请求 | 数据库密文、不同设备登录恢复、另一账号无法读取、密钥错误/移植失败；日志实现复核 |

## 实际依赖审核

未执行安装生命周期脚本，也没有通过改分类、忽略公告来降低告警数。

- Node `24.22.1`：官方安全版本，下载 SHA256 核验；Go `1.27.3`：安全版本；Bun `1.4.4`：npm 分发包 SHA512 完整性核验。
- Next `16.4.3`、React/ReactDOM `19.3.1`、Sharp `0.35.5`、Axios `1.20.0`，以及实际受影响的 pgx、quic-go、x/net、x/crypto 等依赖已升级，锁文件更新。
- 移除只为一个 CSS import 安装的整套 shadcn CLI；原 `4.22.1` CSS 原样保留及注明 MIT 许可证。未改变使用中的 UI 样式实现，也未把依赖改列为 dev 来掩盖公告。
- 对锁文件所有平台包和 Go 模块图共 569 项查询 OSV；更新后的 npm 图无匹配。Go 仍有 3 个模块级公告匹配：goldmark 与 rsc.io/pdf 不在主程序编译依赖中；x/crypto 的匹配为不维护的 openpgp，本程序使用 bcrypt，不导入 openpgp。govulncheck 未报告可达漏洞函数。详见 `evidence/osv-results.json`、`go-module-paths.txt`、`go-runtime-packages.txt`，不能将模块匹配数解释为已证实可利用漏洞数。
- 已实际加载 Node/Sharp 并记录 libvips、rsvg、libpng、libtiff、libwebp、libheif 等 native 组件版本于 `evidence/native-runtime.json`；后续补充最终镜像扫描、签名核验及运行隔离检查，见 [运行组件审核](runtime-review.md)。对静态捆绑原生库仍不能仅凭 npm/OS 扫描宣称全部 CVE 已验收。
- `scripts/security-scan.py` 可重跑锁文件 OSV 和 Go 可达性分析；公告会更新，需要上线前重新执行。

官方基准：[Next 安全公告](https://nextjs.org/blog/nextjs-security-update-october-14-2026)、[Node 安全版本](https://nodejs.org/en/blog/release/v24.22.1)、[Go 发布记录](https://go.dev/doc/devel/release)。
